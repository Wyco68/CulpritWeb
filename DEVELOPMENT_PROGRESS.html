Development Progress

Status update for "The Culprit" — personal academic website & appointment system.
Period: 2026-07-26 – 2026-08-02 Status: In development Environment: Live on Vercel

01 Overview

Backend systems for the appointment feature are built and deployed. Visitors can already book a 30-minute meeting directly through the live scheduling widget on the site. The admin-facing review workflow (approve/decline requests) and the public content pages (Bio, Research, Publications) are next, pending the visual design for those screens.

02 Delivered

AreaWhat it doesStatus
Direct booking Visitors pick an open 30-minute slot on the live "Make Appointment" page and get an instant confirmation — no admin approval needed. Live
Appointment request workflow Full backend for the review path: a request is recorded, the admin can approve, decline, book, or cancel it, and the visitor is emailed at every step. Cancelled/declined requests are kept on record, never deleted. Backend ready
Calendar management (admin) Server-side connection to the scheduling provider so the admin side can list event types, view booked meetings, and cancel a meeting — kept in sync with the appointment record automatically. Backend ready
Spam & abuse protection Bot-challenge and request-rate limits on every public form submission. Live
Admin login Secure single-admin sign-in protecting every management action. Live
Hosting & deployment Production environment configured and deploying automatically from every update. Live

04 Decisions Needed

A few open questions worth a quick decision so the remaining work isn't blocked later:

  • Will a delegated assistant ever need admin access, or is a single admin account sufficient long-term?
  • Preferred email sender/provider for appointment notifications?
  • Should publications be entered manually, or imported from an existing list (e.g. BibTeX/ORCID)?
  • The scheduling provider has no option, on any plan, to auto-create a booking from an approved request — the admin always finalizes those manually in the scheduler. Confirming this is acceptable, or worth exploring alternatives, would be good to settle now.
Full technical detail for all of the above lives in the Project Spec.
